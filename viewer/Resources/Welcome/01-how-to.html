How To
Workflow Folders become Places

Open a folder. Read it like a library.

A Place is a saved local folder. It can be a blog collection, daily report folder, downloaded website archive, documentation pack, or any folder with HTML and Markdown pages.

Steps

Add your first folder.

  1. Choose Places > Add Folder... Pick a folder that contains .html, .htm, .md, or .markdown files.
  2. Select a page. HTTMELY scans the folder and lists readable pages in the sidebar.
  3. Read, reveal, or export. Use the File menu or right-click a page to open it externally, reveal it in Finder, export the folder, or write an archive copy.

Move around quickly.

ActionShortcut
Previous or next pageCommand-[ / Command-]
Toggle page contentsCommand-Option-C
Add a folderCommand-Option-F
Manage placesCommand-Option-,

Removing a Place never deletes your folder. It only removes the shortcut from HTTMELY.
