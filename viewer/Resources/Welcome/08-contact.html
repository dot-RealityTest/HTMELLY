Support Small checks before big debugging

If something looks wrong, start with the folder.

HTTMELY reads local files. Most issues come from missing pages, moved folders, remote assets, unusual exported HTML, or files that need to be regenerated.

Checklist

Useful details to include

  • Your macOS version.
  • The HTTMELY version.
  • Whether the problem happens in one folder or every folder.
  • A sample file if the issue is about page rendering.
  • What you expected to see.

Quick local checks

  1. Confirm the folder contains HTML or Markdown files.
  2. Choose View > Reload.
  3. Reveal the selected file in Finder and confirm it still exists.
  4. Try a smaller folder with one simple index.html.
