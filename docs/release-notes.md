# HTTMELY 1.0.0 Release Notes

HTTMELY 1.0.0 is a local-first macOS reader for folders of HTML and Markdown pages.

## Download

- [HTTMELY-1.0.0.dmg](https://github.com/aka-kika/HTMELLY/releases/download/v1.0.0/HTTMELY-1.0.0.dmg)
- SHA-256: `7af405aab916603d1d765349b8a112abb986017325b97fb26d4519a4a45e356e`

The DMG is signed with Developer ID, notarized by Apple, and stapled for Gatekeeper.

## Highlights

- Opens local folders containing `.html`, `.htm`, `.md`, and `.markdown` files.
- Saves folders as local Places without moving the source files.
- Includes a bundled Welcome collection for first launch.
- Shows examples for blog queues, daily reports, saved websites, Design.md collections, and project packets.
- Provides optional in-page contents navigation from headings.
- Keeps shortcuts and UI state in local user defaults.

## Install

1. Download `HTTMELY-1.0.0.dmg`.
2. Open the DMG.
3. Drag `HTTMELY.app` to Applications.
4. Launch HTTMELY.
5. Use `Places > Add Folder...` for any local HTML or Markdown folder.

## Privacy

HTTMELY does not add cloud sync, uploads, analytics, accounts, remote databases, or external services.
