HTTMELY

A local-first macOS reader for folders of HTML and Markdown pages. Add a folder, switch Places, read quietly, and keep everything on your Mac.

Open Local Folders

Browse `.html`, `.htm`, `.md`, and `.markdown` files without moving them or uploading them.

Save Places

Keep multiple folder shortcuts, rename them for clarity, and switch between page collections quickly.

Read Quietly

Use a native sidebar, page list, and optional contents panel built around local files.

Local-First Contract

HTTMELY does not add cloud sync, analytics, uploads, accounts, remote databases, or external services. Folder shortcuts and UI state stay in local user defaults.
