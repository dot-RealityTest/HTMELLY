## Screenshot Rules

- Use generic folders and content when possible.
- Avoid private paths, names, account details, and unreleased workflow notes.
- Show the app as a local HTML/Markdown reader, not only as a reports viewer.
- Prefer calm pages with real readable content over empty demo screens.
- Keep the sidebar, contents panel, and page body visually clear.

## Optional App Store / Website Copy Pairings

## SEO / GEO Screenshot Notes

- Use concrete alt text that names both HTTMELY and the page type shown.
- Prefer "local page collection" language over generic "screenshot".
- Pair each image with a specific use case: Welcome, Design.md, Saved Sites, or Local Reports.
- Keep screenshots cropped to the app window so social previews and README images look intentional.
